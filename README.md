# Third Person Action Camera

![FF14 对战资料图标](https://xivapi.com/i/000000/000053.png)

FF14 第三人称动作镜头。鼠标直控镜头，准星选目标，按住右键进行 1.65× 平滑变焦。插件加载后默认关闭。

1. 构建当前源码，在 Dalamud 的开发插件设置中添加生成的 `ThirdPersonActionCamera.dll`。
2. 切到第三人称，输入 `/动作模式 开` 启用，`/动作模式 关` 关闭，`/动作模式 设置` 打开设置。`/acti on`、`/acti off` 和 `/acti config` 也可以使用。
3. 默认右肩。移动鼠标转动镜头，按住右键平滑放大，同时按住左右键向前移动。`/acti left`、`/acti right`、`/acti center` 切换肩位，`/acti zoom 2` 临时调整瞄准倍率。
4. 单独长按 Alt 0.5 秒或按住 F10 可临时释放鼠标。隐藏游戏界面时继续控制镜头，并显示已启用的准星。进入聊天、过图、过场、拍照或切离第三人称时释放鼠标。

## 技能目标

直接按热键栏上的目标技能，优先对准星下可用的对象施放（`<mo>`）。准星移开、指向不适用的对象或超出技能范围时，改用当前已选中的可用目标（`<t>`）。例如选中木人后转头看空地，再按攻击技能仍会打这只木人。准星指向另一只可攻击的木人时，下一次按键会打新木人。使用当前目标的按键被游戏接受时，准星会短暂出现浅蓝圆环。

治疗、目标型范围技能和 PvP 单键连击也按这个顺序选目标。开启「释放技能后选中准星目标」，成功施放后会选中受招对象，已排队的技能沿用入队目标。手写宏中的 `<mo>` 在准星落空时取当前选中目标，显式 `<t>` 沿用游戏选中目标。地面技能可在准星落点施放。

## 镜头设置

「显示准星」和「按住右键瞄准」默认开启。「第三人称动态镜头」默认关闭，开启后补足角色跳起时原生镜头尚未跟上的垂直位移。可以调节跟随强度和稳定器。

种族设置控制镜头俯仰和准星位置。「当前职业镜头微调」可以另外调整肩位左右、镜头俯仰和准星位置，切换职业时自动套用。各职业初始偏移为零，「重置当前职业」会恢复该职业使用的种族构图。

## 三个版本

| 版本 | 右键效果 |
| --- | --- |
| v0.4.1 | 沿原版视场角将镜头向人物前移，右肩状态下同时往左收，原版镜头距离足够时约 3×。 |
| v0.5.1 | 1.65× 焦段变焦，光轴朝人物一侧偏转。 |
| v0.5.2 及以后 | 1.65× 纯焦段变焦，肩位和取景方向保持固定。 |

两个 1.65× 版本使用相同的缓动。按住和松开时平滑起停，中途反向会承接当前速度。三个包使用同一个插件标识，每次加载一个版本。

## 验证状态

测试包基于国服 Dalamud API 15。视场角、肩位构图和技能分流已通过离线检查。不同客户端版本和多个镜头插件同时启用的兼容性有待验证。

游戏相机的视场角字段参考 [Cammy 的视场角设置](https://github.com/UnknownX7/Cammy/blob/master/PresetManager.cs#L37-L43)。

## 构建

需要 .NET 10 SDK 和 Dalamud API 15 的程序集。在仓库根目录运行以下命令。把 `DalamudLibPath` 指向包含 `Dalamud.dll` 的实际目录。

```powershell
dotnet build ThirdPersonActionCamera.csproj -c Release '-p:DalamudLibPath=C:/path/to/Dalamud'
```

默认构建纯焦段版。使用 `-p:CameraVariant=Dolly` 或 `-p:CameraVariant=LensWithPan` 可构建另外两个对照版。
